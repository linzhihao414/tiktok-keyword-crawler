# TikTok Keyword Crawler

Search TikTok hashtags by keywords, collect video info, export to Excel.

## Quick Start

1. Edit `keywords.txt` with your hashtags (no # needed)
2. Double-click `run.bat`
3. Results saved in `导出结果/` folder

## What it collects

- Author
- Title/caption
- Views, likes, comments, reposts
- Duration
- Upload date
- URL

No login needed. Uses yt-dlp.
